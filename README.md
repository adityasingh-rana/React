# React — Learning & Practice Projects

> A collection of small React exercises and mini-projects for learning core React concepts:
components, state, forms, routing, context API, Tailwind integration, and small apps.

## About
This repository contains multiple small React projects and activities created to practice React fundamentals. Each folder contains an independent app or exercise (most are simple Create React App / Vite style projects or plain component examples).

**Repository snapshot:** 17 commits; primary languages: JavaScript, CSS, HTML. :contentReference[oaicite:2]{index=2}

---

## Contents / Projects
Each folder is a separate exercise or mini-project. Run the one you want locally by opening its folder and using the usual Node/npm workflow.

- `01_componentInReact` — basic components & rendering examples  
- `02_LikeButton(Activity1)` — like button / activity example  
- `03_ObjectsAndStates` — working with objects and component state  
- `04_ToDoList(Activity2)` — Todo list example  
- `05_LotteryGame` — small game demo  
- `06_Forms` — react forms practice  
- `07_tailwind-in-react` — using Tailwind CSS inside React  
- `08-project-bgchanger` — background color changer project  
- `09-project-posswordGenerator` — password generator app  
- `10-currencyConvertorApp` — currency converter example  
- `11-react-router` — routing examples using React Router  
- `12-miniContext` — mini context API demo  
- `13-contextApi-practice` — additional Context API practice

## How to run a project locally
```bash
git clone https://github.com/adityasingh-rana/React.git
cd React

# Go to any project folder
cd 04_ToDoList(Activity2)

# Install dependencies
npm install

# Start the server (CRA)
npm start

# OR (Vite)
npm run dev
```
